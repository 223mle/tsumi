# プロフェッショナルな図の共通部品

`scripts/charts.py` は、時間軸と閾値をデータから描くSVGレンダラーです。モデルは座標を決めず、意味のある値だけを渡します。

## 色と構造

図の色は、対象を見分けるために固定します。区別に使う色は青・橙・緑の3色までにし、紫はセッションや境界、赤は閾値・危険、灰は補助情報に使います（[図の入力](diagram-input.md)の配色の規則を参照）。`tone`は7色の意味キーから選び、CSS側の`--diagram-blue`などへ結びます。色だけで確度や状態を表さず、ラベルとcaptionにも書きます。

時間軸はすべてのvariantで同じ`min`、`max`、`ticks`を使います。負の時刻を含む場合も、送信や受信を0として同じ軸に置きます。`start`と`duration`から矩形を計算し、ラベルが入らない区間は外側の値欄へ出します。各要素に`data-key`を付けるため、variantを重ねて`data-key`ごとに属性を補間すれば、元資料のbefore/after切替を再現できます。

`groups`を使うと、複数laneを淡い背景帯でまとめ、左側に「受信前に実行可能」「送信後でないと実行できない」のような結論とsummaryを置けます。グループの背景は値の棒より薄くし、棒の値や外側ラベルを隠さないようにします。短い区間のラベルはplotの右側に予約した値欄へ出し、隣の棒へ重ねません。

閾値図は、値の棒と閾値線を同じ軸に置きます。閾値を超えた区間は薄い赤とoutlineで、線だけに頼らず示します。値ラベルは右側の予約欄に置き、長い日本語は2〜3行に折り返します。対数軸を使う場合は、captionに理由と読み方を書きます。測定値・推測値は同じ見た目にせず、図のstatusと説明で区別します。

## アニメーション

比較図には、同じ意味の要素へ同じ`data-key`を付けたvariantを用意します。HTMLには最初のvariantを表示し、ラジオボタン・キーボード操作・`prefers-reduced-motion`対応のJSで切り替えます。動かす要素は座標・幅・透明度だけに限定し、文字の意味や軸を動かして読者を迷わせません。同梱のdiagrams.pyを使うと、JS無効時と印刷時には全variantが静止表示されます。

## 余白と検査

図は1つの主張に絞り、タイトル、短いsummary、図、captionの順に置きます。箱を増やして空白を埋めず、矢印の途中にラベル用の余白を確保します。本文のフォントを縮めて図を詰め込まず、390pxでは縦積みまたは局所スクロールへ切り替えます。

描画検査では、1440pxと390pxの横はみ出し、数値ラベルの不可視化、SVGの`title`/`desc`、キーの対応、明暗テーマ、印刷、JS無効、キーボード切替を確認します。見た目の良さは自動検査だけで保証できないため、スクリーンショットを実際に開き、線と文字の重なりを確認します。
