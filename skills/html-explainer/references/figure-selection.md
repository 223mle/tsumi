# 読者の問いから図を選ぶ

| 読者の問い | 使う図 | 選ばない図 |
| --- | --- | --- |
| 誰が誰に、どの順で何を送るか | sequenceを`mode: "steps"`で1メッセージずつ進める | 全メッセージを同じ濃さで一度に見せる図、矢印に動詞のない図 |
| 何がどこを通るか | 短い直列はflow、往復・分岐・境界はnetwork部品 | 箱の名前だけを矢印で結んだ図 |
| 処理や状態がどう進むか | network・timelineを`mode: "steps"`にし、各段階に1文の説明を付ける | 全段階を1枚に詰め、番号の説明を図の外に並べた図 |
| 何が大きく変わるか | statsブロックで2〜4個の数値を並べ、単位と比較対象を書く | 本文に埋もれた数値、比較対象のない数値 |
| どの処理が長いか | ゼロ起点の横棒。値を外側に置く | 大小の読めない同じ大きさのカード |
| どの処理が重なるか | startとdurationを使うSVG timeline部品 | 並列処理を足し算した積み上げ棒 |
| 何が変わるか | 同じID・軸・色のvariantを1つのbundleにし、同じ場所で補間する | 異なる尺度、色、向きの前後図 |
| どの条件で選ぶか | 2〜3案はcompareブロック、観点が多ければ観点が列・候補が行のtable | 長文を詰めたノード図 |
| どの範囲・権限に属するか | 境界を持つSVG。処理の順序とは分ける | 色だけで境界を表す図 |
| どの量で限界を超えるか | 閾値を明記した棒またはSVGチャート。式と仮定をcaptionへ | 測っていない曲線を滑らかに補間した図 |

図には一つの読み取り課題を持たせる。同じ図が「構成」と「時間」を説明し始めたら二つに分ける。図のタイトルは対象、summaryは読み取り方か結論、captionは条件と根拠に使い、同じ一文を三回繰り返さない。

## 動きを付けるか

動きは、静止画では読み手が頭の中で組み立てる必要がある変化を見せるときに付ける。

- 順序・因果: stepsで1段階ずつ進める。各段階で図のどこかが必ず変わり、説明文がその変化を1文で言う。
- 前後の差: compareで同じ配置・同じ軸のまま補間する。別の図へ瞬時に入れ替えない。
- 流れの向き・量: networkの`motion: true`。点の速さを実測の速さとして説明しない。

数値の大きさだけ、構成だけを示す図は静止のままにする。自動再生はボタンを押したときだけ行い、読み込み時に始めない。

## 数値の図

- 同じ比較には同じ `axis_max` と単位を指定する。自動スケールは単独図向け。
- 正の値の棒はゼロを起点にする。単位が異なる値を同じ軸に置かない。
- timelineでは開始・終了の数値が読めるようにする。細い区間にも外側のラベルを残す。
- 色は同じ対象へ継続して割り当てる。実測・推定の区別は文字で示し、色だけに頼らない。
- 合計、割合、損益分岐点は原データから計算する。個別リクエスト時間の総和を、利用者の待ち時間と呼ばない。
- 入力例は架空である。実測を求められたら実測データが必要であり、例から数値を補わない。

## 特殊なSVGを作る

timeline・network・threshold・decisionの各部品で伝わらない関係に限る。外部スキルが推奨するという理由だけで全図をSVGにしない。

1. 図で答える問い、ノード、動詞付きの辺、境界を列挙する。何を表すか未定の装飾を置かない。
2. 通信の往復ならレーン、分類ならツリー、領域なら囲みを選ぶ。2案が同程度なら、小さく両方を描き、交差・視線の戻り・ラベルの長さを比べる。複雑な図では別エージェントに案への反論を求め、根拠がある指摘だけ反映する。
3. 箱幅・行高・列間隔を定数にし、座標をその関係から導く。長い日本語を一行に押し込まず、意味の切れ目でtspanへ分ける。ラベルは14px以上を出発点とし、縮小後の実画面で判断する。
4. `viewBox`、一意なID付きの `title` と `desc`、`role="img"`、`aria-labelledby`を付ける。重要な説明はfigure外の本文にも残す。矢印の途中にラベルの置き場所を確保し、線を文字や箱に通さない。
5. 横長なら縮小し続けず、焦点を絞った図に分割する。どうしても広い図は、説明とキーボードフォーカス付きの局所スクロール枠に置く。
6. 表現上必要な動きだけを加える。自動再生より読者が進める切替を優先し、`prefers-reduced-motion`では即時切替にする。JSがなくても静止した図と全説明を読めるようにする。

既存のMermaidやユーザー指定があれば使ってよい。単独ファイルが必要な場合は、利用可能なローカルのレンダラーで静的SVGに変換して埋め込み、日本語ラベルとテーマを確認する。実行時CDNへの依存を黙って追加しない。未導入のレンダラーを自動インストールせず、標準部品かSVGで同じ意味を表せるか判断する。
